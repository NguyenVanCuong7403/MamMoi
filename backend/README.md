# Mam Moi - Backend (Scaffold)
This scaffold is an ASP.NET Core minimal MVC-style API using ADO.NET (SqlConnection / SqlCommand).
## How to run
1. Install .NET 7 SDK or later.
2. Open the `backend` folder.
3. Restore and run:
   dotnet run
4. Update `appsettings.json` connection string to point to your SQL Server and database (use the provided Database.txt schema).
## Notes
- This is a minimal scaffold to show ADO.NET patterns. Add authentication, validation, and error handling for production.
